做 Agent 不需要成为 ML 研究员，但完全不懂模型底层会让你在调试和架构决策时抓瞎。这个系列只讲 Agent 工程师用得上的那部分——从推理流程、能力来源到推理框架，够用为止。持续更新中。

**推荐阅读顺序：**

1. 一句话是怎么变成 AI 回复的：LLM 的工作原理 —— 从输入到输出的推理流程
2. 模型的能力是怎么来的：从预训练到 RLHF —— 能力从哪来
3. 推理服务是怎么影响你的 Agent 的：推理框架与架构决策 —— 推理框架对架构意味着什么
